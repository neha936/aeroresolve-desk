Redesign the existing AeroResolve AI frontend to make it feel like a production-grade autonomous AI Agent Command Center, NOT a normal chatbot.

IMPORTANT:
- First inspect the existing Frontend code, current components, routes, API services, and backend response shapes.
- Do not break any existing functionality.
- Do NOT rewrite the backend, Node API, Python AI service, LangGraph workflow, Gemini integration, database, or policy engine.
- Reuse the existing APIs and real data.
- Do not invent fake backend capabilities.
- Do not expose chain-of-thought or private reasoning. Only show observable agent states, tool executions, decisions, and results.
- Keep the current authentication and routing system.
- Use JavaScript/React/Vite as already configured.
- Keep the existing design language but upgrade it significantly.

GOAL:
The application should immediately communicate:
"An AI agent is actively investigating and resolving an airline disruption using tools and policies."

The Chat UI should become secondary. The Agent execution, tools, case context, decision, action, and verification should become the primary experience.

Layout:

- subtle violet/blue/cyan gradients

- thin borders
- soft glows
- high-quality typography
- smooth micro-interactions
- subtle 3D depth
